# Overrides probados para Windows

`gemini.lua` es una sustitucion completa del archivo `lua/plugins/gemini.lua` de GentlemanNvim, probada con la configuracion de referencia.

Para `nodejs.lua` y `lazy.lua`, ver `../README.md`. No copiar los archivos completos de Mac: contienen otras personalizaciones y podrian cambiar. El proceso reproducible para esas dos correcciones se incorporara despues de cotejar la version exacta del equipo Windows y la configuracion fuente.
